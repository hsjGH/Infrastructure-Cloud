# Infrastructure & Cloud Repository

This repository contains all practical exercises, scripts, and projects for the **Infrastructure and Cloud** course. The content is organized into specific folders based on topics, technologies, and tools used throughout the course.  

---

## Repository Structure

| Folder | Description |
|--------|-------------|
| `01-Data_Formats_and_Models` | Python scripts and exercises related to data formats, data models, and basic object-oriented programming. |
| `02-API` | Scripts demonstrating API usage, REST calls, and working with external APIs. |
| `03-Netmiko_Restconf_and_Netconf` | Network automation scripts using Netmiko, RESTCONF, and NETCONF. |
| `04-DNAC_of_Catalyst_Center` | Experiments and configurations using Cisco DNAC or Catalyst Center. |
| `05-Ansible_Playbooks_Network` | Ansible playbooks for network device automation (e.g., backups, IPv6 configuration, banners). |
| `06-Ansible_Playbooks_Server` | Ansible playbooks for server management and deployment (e.g., Apache installation, service management). |
| `07-Python_Virtual_Envirnment_venv` | Python virtual environment exercises and setup examples. |
| `08-Python_Flask_Microservices` | Flask web applications and microservice projects. |
| `09-Docker` | Docker exercises, including image creation, container management, and Docker orchestration. |
| `10-Jenkins_Pipelines` | Jenkins pipeline scripts and CI/CD exercises. |
| `11-Webex` | Scripts and experiments interacting with Webex APIs or automating Webex tasks. |
| `12-Unitest` | Python unit testing exercises and examples. |
| `13-Automation_Iac_and_Cisco_Platforms` | Self-study projects covering Infrastructure as Code (IaC) and Cisco platform automation. |
| `14-Self_Study` | Additional experiments, notes, and self-study projects related to infrastructure and cloud. |

---

## Key Technologies

- Python 3 (OOP, scripting, API interaction, Flask)
- Ansible (playbooks for network and server automation)
- Cisco network automation (Netmiko, RESTCONF, NETCONF, DNAC)
- Docker (images, containers, management)
- Jenkins (CI/CD pipelines)
- Webex automation
- Unit testing (Python `unittest`)
